# Mood journal
This is a mood journal to help you understand your feelings, and analyse them over a period of time. 

Using pandas, this journal will read your emotions, help you analyse what caused the emotion, and your general response over time.

You can also edit the list of emotions, and the feeling associated with them.

## Usage guide:

  1. Make sure you have python installed by running this code:
     
     - For linux:
       ```
       python3 --version
       ```

       If not installed, install using the following terminal commands, based on your distro:

       - Debian:
         ```
         sudo apt install python3
         ```
         ```
         sudo apt install python3-pip
         ```
      
       - Fedora:
         ```
         sudo dnf install python3
         ```
         ```
         sudo dnf install python3-pip
         ```
      
       - Arch:
         ```
         sudo pacman -S python
         ```
         ```
         sudo pacman -S python-pip
         ```
      
       - CentOS/Red Hat:
         ```
         sudo yum install python3
         ```
      
       - openSUSE:
         ```
         sudo zypper install python3
         ```
